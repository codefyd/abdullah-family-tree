# مشجرة عائلة عبدالله (خريطة ذهنية)

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الموقع كاملًا في ملف واحد (البيانات الأصلية مضمّنة داخله) |
| `family-data.json` | ملف البيانات الأصلي، بنفس صيغة «تصدير ملف البيانات» ويمكن استيراده |
| `CLAUDE.md` | مواصفات المشروع وبيانات العائلة (مصدر الحقيقة) |

## التشغيل

- افتح `index.html` مباشرة في أي متصفح حديث (كروم، إيدج، سفاري، فايرفوكس). لا يحتاج تثبيتًا ولا إنترنت.
- الخط العربي (IBM Plex Sans Arabic) يُحمَّل من الإنترنت إن توفر، وإلا تُستخدم خطوط النظام تلقائيًا.
- للنشر: ارفع `index.html` وحده على أي استضافة ملفات ثابتة.

## الاستخدام

- **التنقل:** اسحب بالفأرة أو الإصبع، وكبّر بعجلة الفأرة أو بإصبعين. أزرار الزاوية: تكبير، تصغير، ملاءمة الشاشة، التمركز على الجد. الخريطة المصغرة قابلة للنقر والسحب.
- **التخطيط:** زر أعلى الشاشة يبدّل بين «يمين ويسار» و«شعاعي».
- **الطي والفتح:** الرقم الصغير على كل أب هو عدد أبنائه؛ انقره لطي الفرع أو فتحه.
- **البحث:** اكتب الاسم فتظهر كل النتائج مع النسب، واختيار نتيجة يحرك الخريطة إليها ويبرز خط النسب من الجد.
- **بطاقة الشخص:** انقر أي شخص لتعديل بياناته، رفع صورة أو حذفها، إضافة ابن أو بنت، أو حذفه (إن لم يكن له أبناء).
- **الحفظ:** كل تعديل يُحفظ فورًا في ذاكرة هذا المتصفح فقط. من القائمة (⋯): تصدير ملف البيانات، استيراد ملف بيانات، تصدير الخريطة كصورة PNG، فتح كل الفروع، إعادة الضبط.
- اختصارات لوحة المفاتيح: `+` و`-` للتكبير والتصغير، `0` لملاءمة الشاشة، `Esc` لإغلاق البطاقة.

## اقتراح المرحلة الثانية (للنقاش، لم يُنفذ)

1. **قاعدة بيانات مركزية:** نقل البيانات من ذاكرة المتصفح إلى قاعدة بيانات مستضافة (مثل Supabase أو Firebase) بنفس صيغة الحقول الحالية، مع سجل تعديلات (من غيّر ماذا ومتى) وإمكانية التراجع.
2. **الصلاحيات:** ثلاثة أدوار: مشاهد (يرى فقط)، محرر فرع (يعدّل فرع أبيه وأبنائه)، ومشرف (يعتمد التعديلات ويدير الأعضاء). التعديلات الحساسة مثل الحذف أو تغيير الأب تمر باعتماد المشرف.
3. **رابط خاص للعائلة:** رابط غير مفهرس في محركات البحث، يُفتح بدعوة أو رمز دخول يُرسل بالجوال أو البريد، مع إمكانية إلغاء الرابط وتوليد غيره.
4. **الصور:** تخزين الصور في مساحة ملفات منفصلة بدل داخل البيانات، لتخفيف الحجم.
5. **الترحيل:** زر «رفع بياناتي» يأخذ ملف التصدير الحالي ويدمجه في القاعدة المركزية، فلا يضيع ما أُدخل في المرحلة الأولى.
